# Hyperoid-cli-agent

An autonomous tactical cyber-ops AI terminal HUD for Android/Termux powered by Gemini 2.5 Flash.

---

## ⚡ Quickstart

```bash
# 1. (Optional) Enable Android hardware integration
pkg install termux-api -y

# 2. Clone repository & run installer
git clone https://github.com/suyogpawate-lab/Hyperoid-cli-agent.git
cd Hyperoid-cli-agent
bash install.sh

# 3. Launch HUD
hud
```

---

## 🎮 Controls & Triggers

* **Text Prompts:** Type commands into `[AGENT_CMD] >`
* **Clear Memory:** Type `clear` to purge short-term buffer
* **Exit Session:** Type `exit` or `quit`
* **Automated Actions:** `turn on flashlight`, `open youtube`, `install github repo user/repo`
